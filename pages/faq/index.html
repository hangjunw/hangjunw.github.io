常见问题

编辑本页

关于站点维护、权限申请、数据使用与内容添加的常见问题。

一、如何新增一个条目？

在对应板块下新建一个目录，目录里放一个 index.md：

content/projects/my-new-project/index.md

写下 front matter 与正文，运行 python build.py，站点自动出现新节点。不需要改任何配置，除非你要新增板块。

二、如何新增一个子节点？

在同一个目录里再放一个 .md 文件，例如 content/projects/my-new-project/code.md：

content/projects/my-new-project/
├── index.md      # 主节点
├── code.md       # 子节点：配套代码
└── data.md       # 子节点：配套数据

三、如何新增整个板块？

  1. 在 content/ 下新建一个目录，例如 content/softwares/
  2. 在 config/collections.json 的 collections 里加一段配置（可以复制 patents 那段改几个字段）
  3. 在 config/site.json 的 nav 里加一行导航

四、如何申请修改权限？

联系管理员（默认 chenyuzhou）或在 Issue 中提出，说明需要管理的板块 / 节点范围。管理员在 config/access.json 的 grants 里加一行即可生效。

五、草稿会不会被别人看到？

会。草稿标记 draft: true 只会在构建时显示"草稿"标签，不会阻止页面生成。正式发布前请先去掉该标记，或让管理员审核后再合并。

六、数据要不要脱敏？

必须。对外发布的数据集一律脱敏；涉及合作方隐私的图像需裁剪或模糊处理后再放。
